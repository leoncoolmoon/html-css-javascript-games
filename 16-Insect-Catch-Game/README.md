# Insect Catch Game / 捕虫游戏

Test your reflexes by clicking on randomly appearing insects to catch them before they disappear. 🐞

通过点击随机出现的昆虫来测试你的反应能力，尽量在它们消失之前捕捉到它们。 🐞
