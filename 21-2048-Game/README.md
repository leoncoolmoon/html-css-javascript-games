# 2048 Game / 2048 游戏

Slide numbered tiles on a grid to combine them and create a tile with the number 2048 in this addictive puzzle game. 🧩

在这个上瘾的益智游戏中，滑动数字方块以组合它们并创建一个数字为 2048 的方块。 🧩
