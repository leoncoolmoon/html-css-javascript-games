# Guess Number Game / 猜数字游戏

Guess a 4-digit number with A for right position and B for right number. Only eight chances. A good game for logical thinking.🧠🤖

猜测一个 4 位数字，A 表示位置正确，B 表示数字正确。只有八次机会。一个锻炼逻辑思维的好游戏。🧠🤖
