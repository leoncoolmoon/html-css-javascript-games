# Hangman Game / 绞刑架游戏

Guess the hidden word by suggesting letters within a certain number of guesses in this word-guessing game. You can also check the definitions of the words with internet 🎩

在这个猜字游戏中，通过在有限的猜测次数内建议字母来猜测隐藏的单词。并能通过网络查询该词的读音和解释 🎩
