# Minesweeper Game / 扫雷游戏

Exercise your logical thinking with this puzzle game where you avoid hidden mines and uncover safe tiles. 💣

经典的扫雷游戏，左键打开方块，推开（长按）标记方块，双击打开周围的方块。 💣
