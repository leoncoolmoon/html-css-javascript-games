# Flappy Bird Game / Flappy Bird 游戏

Guide a bird through gaps in pipes by tapping to flap its wings, avoiding obstacles and aiming for a high score. 🐦

通过点击来引导鸟儿穿过管道间隙，避免障碍物并争取高分。 🐦
