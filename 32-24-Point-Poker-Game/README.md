# 24 Point Poker Game / 24 点扑克

A classic 24 point poker game. Get four random cards to start. Use Add or Subtract or Multiply or Divide to calculate 24. 🎲🃏

一个益智计算类游戏，随机取四张扑克牌用加减乘除四则运算来计算24 点！🃏
