# Snake Game / 贪吃蛇游戏

Control a growing snake, eat food, and avoid collisions with walls and your own tail in this nostalgic arcade game. 🐍

控制一条不断生长的蛇，吃食物，避免与自己的尾巴发生碰撞，在这个怀旧的街机游戏中，支持重力感应。 🐍
