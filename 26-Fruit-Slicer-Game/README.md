# Fruit Slicer Game / 水果切割游戏

Swipe across the screen to slice falling fruits while avoiding bombs in this fast-paced fruit-slicing game. 🍉🔪

在这个快节奏的水果切割游戏中，划过屏幕切割掉下来的水果，同时避免炸弹。 🍉🔪
