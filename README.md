# [HTML/CSS and JavaScript Games Collection / HTML/CSS 和 JavaScript 游戏合集](https://leoncoolmoon.github.io/html-css-javascript-games/) 🎮

A modernized, decentralized, and Progressive Web App (PWA) collection of 48 interactive games. 🎯🕹

一个现代化、去中心化的渐进式 Web 应用程序 (PWA) 游戏合集，包含 48 款互动游戏。 🎯🕹

## Key Features / 主要特性 🚀

- **Modern UI**: A responsive, card-based grid layout built with CSS Grid and Flexbox.
- **现代 UI**: 使用 CSS Grid 和 Flexbox 构建的响应式卡片式网格布局。
- **Multilingual**: Unified English and Chinese support with seamless switching.
- **多语言**: 统一的中英文支持，可无缝切换。
- **Decentralized Architecture**: Game metadata (names and descriptions) is stored locally within each game's `README.md` for easier maintenance.
- **去中心化架构**: 游戏元数据（名称和描述）存储在每个游戏的 `README.md` 中，更易于维护。
- **PWA Support**: Installable on mobile and desktop with offline caching capabilities.
- **PWA 支持**: 可在移动端和桌面端安装，具有离线缓存功能。
- **Search Functionality**: Real-time filtering to find your favorite games instantly.
- **搜索功能**: 实时过滤，瞬间找到你喜爱的游戏。

## How it Works / 工作原理 🛠

The project uses a data-driven approach: / 该项目采用数据驱动的方法：
1. Each game directory contains a `README.md` with an embedded JSON metadata block (`GAME_META`). / 每个游戏目录都包含一个 `README.md`，其中嵌入了 JSON 元数据块 (`GAME_META`)。
2. The root `path.js` defines the list of available games. / 根目录下的 `path.js` 定义了可用游戏的列表。
3. The main `index.html` dynamically aggregates this data to render the home page. / 主页面 `index.html` 动态汇总这些数据以渲染主页。
