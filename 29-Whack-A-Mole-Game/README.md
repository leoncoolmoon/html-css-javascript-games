# Whack A Mole Game / 打地鼠游戏

Test your reaction speed by hitting randomly appearing moles with a mallet before they disappear in this classic arcade game. 🕹️

通过在这个经典街机游戏中用锤子击打随机出现的地鼠来测试你的反应速度。 🕹️
